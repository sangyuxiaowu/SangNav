# 云端账户与数据存储

账户、密码和会话使用 AES-256-GCM 加密后保存在 IndexedDB，密钥为不可导出的 Web Crypto CryptoKey，不保存明文密码。刷新或重新打开页面自动恢复有效会话；到期前及接口返回 `401` 时，使用加密凭据自动重新登录获取新令牌。服务器不提供 refresh token，此处调用现有资源登录接口，不延长原令牌有效期。

自动重新登录仍受服务端登录限流约束；密码错误或账户禁用时停止自动重试、清除保存的账户凭据并保留数据草稿，需要手动重新登录。网络异常不会删除已保存的账户。退出账户会删除加密凭据和密钥。加密存储要求安全上下文（HTTPS 或本机开发地址）及 IndexedDB；不可用时会提示刷新后需手动登录。加密不抵御同源恶意脚本或已被控制的浏览器，仅避免凭据明文落盘；只在可信设备上使用。

需要服务端允许当前网页来源访问 API。空间地址要求 HTTPS，本机 `localhost`、`127.0.0.1` 和 `::1` 开发地址可使用 HTTP。登录后检查 `/capabilities` 的 `apiVersion=v1`、Bearer/workspace 认证，以及 `resources.json`、`resources.conditions`、`commits.atomic`；缺少必需能力则拒绝连接。读取实际 `limits` 约束分页、正文、附件及提交大小，不调用未实现的分享、AI 或离线同步接口。登录 `429` 按 `Retry-After` 阻止提前重试，自动登录的临时失败稍后重试，不立即清除账户。

云端数据归属规范化的空间 URL，同一 URL 的资源账号看到同一套数据，不同 URL 相互隔离。云端键不包含账号 ID，不再使用单快照。资源格式为 `sangnav.resource`、版本 `1`，JSON 正文使用 `{ "value": ... }` 包络，以支持空图案锁等空值。

| 逻辑键 | 内容 |
| --- | --- |
| `app.json` | 数据格式标识 |
| `settings.json`、`wallpaper.json` | 一般偏好、壁纸及附件引用 |
| `links/<id>.json`、`categories/<id>.json` | 单个书签、单个分类 |
| `links/order.json`、`categories/order.json` | 顺序及完整性清单 |
| `secret/links/...`、`secret/categories/...` | 私密书签、分类和顺序 |
| `secret/pattern.json`、`secret/autolock.json` | 图案锁及自动锁定 |
| `search/engines.json`、`search/active.json`、`search/history.json` | 搜索配置和历史 |
| `analytics/visits/<日期>.json`、`analytics/searches/<日期>.json` | 按日分片的访问和搜索统计 |

启动时分页列出摘要，再读取已知格式资源；未知键和未知格式保持不动。云端访问统计与书签内容分离，点击不会更新书签版本。未发布版本不迁移旧 `sangnav.snapshot` 或旧账号键，旧资源不删除；升级前应在旧版导出完整备份，在新版登录目标空间后恢复。

保存只提交变化的资源，通过 `/commits` 传递完整资源及各自的 `expectedVersion`；`null` 表示创建，正整数表示条件更新或删除。这是资源级增量保存，不是 JSON 字段级 PATCH。普通提交按能力响应的 `limits.commitOperations` 校验，不额外硬编码 50，但当前服务端仍限制单次最多 50 项。公共导航、私密导航及偏好组的关联修改各自保持原子性，只有明确独立的组允许分别提交。

首次完整同步、完整备份恢复均要求一次原子发布；超限时不发送部分提交，保留完整本地数据与待同步计划，明确提示现有协议能力不足，不标记同步成功，也不要求删除数据规避限制。服务端正在评审分批暂存、持久进度与回执、最终一次事务原子发布协议，尚未实现、端点和字段未定稿，本客户端不调用或模拟该能力。

断网、认证失效或版本冲突会保留草稿，不显示已保存。提交超时、网络中断、`5xx` 或无效回执显示“结果待确认”，重新编辑或刷新也不会直接重放；「核实并重试」先读远端，已包含本次内容则确认，否则按原草稿基线检查，不能为了消除冲突读取最新版本覆盖旧草稿。冲突时先完整备份，再选择读取云端或进行业务合并。

分页结果先进入候选缓冲，加载正文、核对已知键并校验顺序和分类引用后再使用；检查失败保留本地视图，不能根据分页缺失项生成删除。总数不变、无重复 key 不能证明完整或同一修订；当前尚无服务端读取修订栅栏，客户端检查不能替代跨请求快照保证。需要严格保证时应等待相应公开能力，不宣称已支持。

已删除资源 UUID 不可复用。恢复历史内容必须创建新 UUID 并更新相关业务引用；当前仍存在的资源回退内容，则基于当前草稿对应的 JSON 版本正常条件更新。服务端源码生成强数字 ETag；接入部署曾出现弱 ETag，原因尚未确认，不推定是源码、压缩或代理导致。

退出后恢复原本机数据，不把云端内容写入本机模式。草稿按服务地址、空间 URL 和资源身份隔离，下次以相同身份登录相同空间时恢复，不会把上一身份的未保存修改自动上传；这不改变云端数据的空间级共享语义。浏览器存储不足时提示立即完整备份。完整备份包含私密导航、图案锁和统计，普通导航备份仍只包含普通导航数据。注销返回 `401` 视为会话已失效；其他注销失败仍清除本机令牌并显示错误。

本地壁纸以原始图片字节上传，检查附件能力、大小、SHA-256 和返回的媒体类型后，在 `wallpaper.json` 中声明附件引用。下载再次校验大小和 SHA-256。上传已收到 ID 但校验失败时，错误对象的 `attachmentId` 和本机待核查记录保留该 ID，便于核查清理；不能复用未通过校验的附件。已验证上传在资源提交失败后仍保留标识，核实重试时复用，不重复上传。不把整个数据集作为附件保存。单个书签、日统计分片等仍受正文大小上限约束，超限会保留草稿并提示。附件历史受服务端修订保留策略约束，不自动删除历史或未引用附件，需部署者管理。天气和远程图标仍为本机缓存，自定义图标配置随对应书签资源保存。

服务端与本机草稿均无端到端加密，私密导航和图案锁也会上传。空间内资源账号具有整个空间的读写权限；需要权限隔离时使用不同空间。勿在不可信设备上登录或保留完整备份。

云端 HTTP 回归测试：`bun run test`。使用独立临时 HTTP 服务和测试凭据，覆盖能力校验、空间共享、分页、未知资源、局部保存、原子失败、冲突及结果核实、附件完整性和认证恢复，不接触部署数据。真实部署仍需配置 CORS 并使用实际空间资源账户联调。
