# 轻启 SangNav · 个人智能极简起始页

> **高效、优雅、私密的个人浏览器起始页与聚合导航系统**  
> 集成实时天气、多引擎聚合搜索、网址与分类编排、壁纸毛玻璃视觉定制、访问统计分析及私密保险库空间。

---

## ✨ 核心特性

### 🔍 1. 多引擎聚合搜索
- **主流引擎预设**：内置必应 (Bing)、百度 (Baidu)、DeepSeek (深度求索 AI)、谷歌 (Google)、GitHub、哔哩哔哩 (Bilibili)、知乎 (Zhihu)、豆瓣 (Douban) 等高质量引擎。
- **自定义排序与拖拽**：设置中心支持点击上下箭头移动及鼠标拖拽重排，主页搜索栏标签实时按自定义顺序呈现。
- **启用/停用滑块**：每个搜索引擎配备独立开关滑块，随心启停；智能防空与默认引擎自动回退机制。
- **自定义引擎全配置**：
  - 支持配置名称与快捷键标识；
  - 开放自定义 **占位提示词 (Placeholder)**，定制个性化引导文案；
  - 开放 **主题辨识色彩 (Color)** 设置，提供丰富品牌预设色盘及原生色谱吸管；
  - 支持对已有引擎进行二次编辑更新。
- **书签即时检索**：一键切换「书签检索」模式，实时模糊匹配本地收藏网址并快速直达。
- **搜索历史管理**：自动记录高频搜索词，支持一键清空或删除单条历史。

### 📌 2. 网址与分类精细编排
- **多维度分类**：预置常用高频、AI 智创、技术开发、设计灵感、效率工具、资讯影音等分类，支持自定义分类命名、图标与排序。
- **快捷整理模式**：点击分类栏「卡片整理」即可进入管理模式，支持卡片拖拽排序、批量调整置顶与快速编辑。
- **置顶快速坞 (QuickDock)**：高频访问网址一键 Pin 置顶，在主页形成精致悬浮 Dock 栏。
- **智能 Favicon 抓取与缓存**：支持 Google、Icon Horse、十月图标、站点原生等多家图标源，本地 IndexedDB 离线缓存，告别图标失效与慢加载。

### ⛅ 3. 动态时钟与实时 IP 天气
- **实时精美时钟**：动态秒级数字时间、农历/公历日期与问候语。
- **精准天气预报**：基于客户端 IP 自动匹配城市天气（气温、体感、湿度、风向风级、未来多日预报及气象灾害预警），支持手动指定城市或 IP 查询。

### 🎨 4. 个性化主题与壁纸系统
- **6 套主题调色**：深邃暗夜、星空蔚蓝、极简明亮、翡翠沉木、暖调流金等色彩氛围。
- **网格密度切换**：支持 3 列、4 列、5 列、6 列响应式栅格卡片布局。
- **壁纸中心**：
  - 每日精选：必应每日超清摄影壁纸（每日自动刷新）；
  - 风格壁纸：壮阔山峦、极光幻夜、极简光影、赛博霓虹、晨曦森林等；
  - 自定义壁纸：支持上传本地高清图片或输入网络图片 URL 直链；
  - 视觉调节：背景遮罩对比度暗度滑块（0% ~ 85%）与背景毛玻璃高斯模糊滑块（0px ~ 25px）。

### 🔒 5. 私密导航空间 (Secret Space)
- **手势图案锁保护**：采用九宫格图形密码锁，端到端本地验证。
- **快捷伪装与唤出**：
  - 连续按 3 次 `Alt` 键或点击时钟特定区域即可唤出解锁界面；
  - 浏览私密空间时，按 `Esc` 键或窗口失焦可自动快速锁屏伪装退出。
- **独立私密库**：私密书签与公有书签严格物理隔离，私密空间不参与公共搜索推荐与访问记录统计。

### 📊 6. 本地数据隐私与统计分析
- **访问与搜索统计**：基于 IndexedDB 本地记录点击热度、高频时段偏好与搜索词分布，提供可视化分析图表。
- **零追踪·绝对隐私**：所有书签、配置及使用数据均保存在本地浏览器（LocalStorage 与 IndexedDB），无任何外部云端数据上传与分析代码。
- **全量备份与迁移**：支持导出标准 JSON 数据备份，并在任何设备上一键导入恢复。
- **PWA 渐进式离线支持**：支持安装到电脑与手机桌面，拥有原生 App 般的全屏流畅体验，内置版本检测更新机制。

## ⌨️ 常用快捷键

| 快捷键 | 功能说明 |
| :--- | :--- |
| `/` 或 `Ctrl + K` | 快速聚焦搜索栏输入框 |
| `Alt + N` | 快速打开添加新网址弹窗 |
| 三击 `Alt` | 呼出私密导航空间解锁面板 |
| `Esc` | 在私密模式下立即锁屏伪装退出 / 关闭当前弹窗 |
| `Enter` | 在搜索框内直接唤起引擎搜索 |

## 🛠️ 技术栈

- **框架**：React 19 + TypeScript + Vite
- **样式**：Tailwind CSS + Lucide Icons
- **存储**：LocalStorage（偏好配置）+ IndexedDB（访问统计与 Favicon 离线缓存）
- **离线与应用**：PWA (Progressive Web App) + Web Worker
